# StyleSense Public Website Restructure

## Goal
Turn the public-facing StyleSense website into a premium fashion-lifestyle product site, while leaving wardrobe, recommendation, account, and admin functionality intact.

## Public website
- Rework Home around a full-bleed fashion hero, compact floating navigation, editorial imagery, generous spacing, and warm StyleSense colors.
- Keep Home as a focused long-form story: introduction, process, feature highlights, style intelligence, community, No New Clothes, testimonials, app preview, FAQ preview, and final download prompt.
- Create dedicated Features, How It Works, About, Testimonials, and FAQ pages with distinct, useful content rather than duplicating Home.
- Replace the generic missing-page view with a branded StyleSense 404 page.

## Navigation and routing
- Use dedicated public routes for every marketing page.
- Keep app routes and the separate `/admin` area unchanged.
- Use a compact desktop navigation and accessible mobile menu with “Get the App” as the primary action.

## Visual direction
- Treat the provided image as composition and atmosphere reference only.
- Generate original fashion imagery showing real wardrobe use, outfit discovery, confidence, and everyday dressing.
- Use Bagel Fat One for display text and Baloo Tamma 2 elsewhere.
- Apply #ffd586, #756e9e, and #faf7f2 through semantic theme tokens.
- Avoid gradients, glass effects, excessive cards/icons/animation, and generic product-site patterns.

## Validation
- Check all public routes, navigation links, app/admin route preservation, page metadata, desktop layout, and mobile layout.
- Resolve any build or runtime errors before completion.
